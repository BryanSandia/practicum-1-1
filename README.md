# Practicum 1.1 - Análisis de Dataset de Películas

## Declaración de Uso de IA Generativa
Este proyecto ha utilizado herramientas de IA generativa (Qwen) como asistente de apoyo para:
1. Generación de comandos de terminal (bash) para el exploración inicial del dataset.
2. Redacción y formato de referencias bibliográficas en normas APA 7.
3. Estructuración del repositorio y sugerencias de limpieza de datos.

**Revisión humana:** Todo el código, las consultas SQL, los diagramas y el análisis de los datos han sido verificados, comprendidos y validados manualmente por los integrantes del equipo. La IA no ha generado decisiones de negocio ni lógica de modelado sin supervisión.

## Estructura del repositorio
- `data/raw/`: Dataset original sin modificar.
- `docs/`: Diagramas E/R y documentos editables.
- `src/`: Código Scala para limpieza, transformación y consultas.
